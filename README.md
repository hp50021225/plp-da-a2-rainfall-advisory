# County Rainfall and Planting Advisory

**Author:** Harith Parvez · PLP Data Analytics Cohort 7  

## Project Summary
This project analyzes monthly rainfall data across five Kenyan counties (Nairobi, Nakuru, Kisumu, Mombasa, and Machakos) to assist a farmer-support NGO in determining optimal planting windows and drought priorities.

## Planting Advisory
* Farmers in high-rainfall regions like Kisumu should prepare fields ahead of the peak March–April long rains.
* Coastal and Machakos agricultural zones require careful water conservation strategies due to extended dry months and lower annual totals.
* Planting schedules must be aligned with the identified two-month peak windows to maximize germination success and crop resilience.
